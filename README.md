IIIT Event Board

A responsive event board website developed as part of the Web Development Lab assignment. The website displays upcoming events, schedules, FAQs, registration details, and contact information for IIIT students.

Features

* Responsive event board layout
* Upcoming event cards
* Event schedule table
* FAQ section using HTML <details> and <summary>
* Registration form
* Contact page
* Responsive navigation
* Mobile and desktop layouts
* CSS Grid-based page layout
* Responsive event card grid
* Responsive images
* Light and dark theme styling
* Background image
* Accessible navigation and semantic HTML elements

Technologies Used

* HTML5
* CSS3
* CSS Grid
* Responsive Web Design

Contact Page

The contact page provides event-related contact information, including email and phone details.

Responsive Design

The website follows a mobile-first approach and adapts to different screen sizes using:

* CSS Grid
* auto-fit and minmax()
* Flexible units such as %, rem, and vw
* clamp() for fluid sizing
* Media queries for larger screens

CSS Structure

* base.css contains common/basic styling.
* style.css contains the main layout, colors, typography, cards, grid, and responsive design.
* theme-dark.css contains dark-theme styling.

How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in a web browser.

No additional software or dependencies are required.
